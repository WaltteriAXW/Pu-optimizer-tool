## Database Overview

### 🌍 By Blowing Agent

#### Water-Blown (Environmentally Friendly)
- **GWP:** 0 (zero emissions)
- **Best for:** Cost-conscious, eco-conscious applications
- **Drawback:** Longer cream/gel times
- **Materials:** Ecofoam HD12, Genfoam HD20, Flexo Soft/Medium, Semirigid, General Pour Foam

#### Ecomate® Blown (Ultra-Eco)
- **GWP:** 0 (zero emissions)
- **Best for:** Premium green applications
- **Advantage:** Fast processing, excellent insulation (k-factor)
- **Materials:** Ecomate Spray Grade, Ecofoam XHD RC

#### HFO-Blown (Low-GWP)
- **GWP:** 1-10 (near-zero)
- **Best for:** Compliant but needing performance
- **Drawback:** Cost premium
- **Materials:** Various HFO alternatives (spec on request)

#### HFC-Blown (Traditional)
- **GWP:** 1000+ (still used in some applications)
- **Status:** Phased out in most regions
- **Note:** Avoid for new projects

## Material Specifications

### **1. Ecofoam HD12 (Standard) ⭐ Most Popular**

**Category:** Rigid foam, water-blown

**Basic Properties:**
```
Polyol viscosity:     900-1050 cP
Isocyanate viscosity: 250-300 cP
Mixed density:        1100-1120 kg/m³
Free-rise density:    195-215 kg/m³
```

**Processing Windows:**
```
Cream time:           50-60 seconds
Gel time:             120-150 seconds
Tack-free time:       6-8 minutes
Temperature range:    20-30°C (optimal 25°C)
Pressure range:       2-150 bar
```

**Rheological Properties:**
```
Flow index (n):       0.85 (shear-thinning)
Consistency (K):      0.65 Pa·s
Yield stress:         2-3 Pa
Activation energy:    25,000 J/mol
```

**Quality Specifications:**
```
Compressive strength: 80-120 kPa (parallel)
Tensile strength:     150-250 kPa
Elongation:           10-30%
Closed-cell content:  70-85%
Thermal k-factor:     0.028-0.035 W/m·K
Max temperature rise: 8°C
Max pressure drop:    50 bar
```

**Environmental:**
```
Blowing agent:        Water
GWP:                  0 kg CO2-eq
ODP:                  0
PFAS-free:            Yes
Biodegradable:        Yes
```

**Best for:**
✅ General purpose molding
✅ Insulation panels
✅ Standard production
✅ Cost-sensitive projects
✅ Eco-conscious buyers

**Typical Processing:**
```
Inlet temp: 25°C
Flow rate: 10 L/min
Pipe: 20mm × 1000mm
Result: 12.3 bar, +2.1°C rise
```

### **3. Ecomate Spray Grade ⚡ Ultra-Fast**

**Category:** Spray foam, zero-GWP, FASTEST

**Basic Properties:**
```
Polyol viscosity:     280-320 cP ← VERY LOW!
Isocyanate viscosity: 200-250 cP
Free-rise density:    28.8-32.0 kg/m³
```

**Processing Windows:**
```
Cream time:           1-5 seconds ← EXTREMELY FAST!
Gel time:             7-13 seconds
Tack-free:            30-60 seconds
Temperature:          25-30°C (critical!)
```

**Characteristics:**
- Ultra-low viscosity = tiny droplet size
- Excellent spray pattern
- Fast rising = less sagging on vertical surfaces
- Fast cure = quick demolding

**Best for:**
✅ Spray foam applications (roofing, insulation)
✅ Open-cell applications
✅ Fast cycle time needed
✅ Zero GWP requirement
✅ Insulation with low density

**⚠️ Critical:** Must use spray equipment designed for low-viscosity materials!

## Advanced Properties

### Temperature Sensitivity

**How viscosity changes with temperature:**

For **Ecofoam HD12** (Ea = 25,000 J/mol):
```
20°C:  400 cP
25°C:  350 cP (reference)
30°C:  305 cP (-13%)
35°C:  265 cP (-24%)
40°C:  230 cP (-34%)
```

**Impact on processing:**
- Higher temp → Lower viscosity → **Lower pressure drop** ↓
- Every 10°C increase ≈ 25-35% viscosity reduction
- Critical for pressure management!

### Pressure Effects

All materials have slight compressibility. At elevated pressure:
```
0 bar:    density = 1100 kg/m³ (reference)
50 bar:   density ≈ 1105 kg/m³ (+0.5%)
100 bar:  density ≈ 1110 kg/m³ (+1%)
150 bar:  density ≈ 1118 kg/m³ (+1.6%)
```

Negligible for most applications.

## Custom Materials

If your material is not in the database:

1. **Gather specifications:**
   - Polyol viscosity @ 25°C
   - Isocyanate viscosity @ 25°C
   - Free-rise density
   - Cream & gel times
   - Flow index (0.7-0.9 typical)
   - Consistency coefficient
   - Activation energy (20,000-35,000 J/mol typical)

2. **In the app:** Click "Create Custom Material"

3. **Fill in specs:**
   - Give it a name
   - Enter all properties
   - Save for future use

4. **Use in calculations:** Select your custom material from dropdown

## Processing Troubleshooting

### "Pressure is too high"
**Check:**
1. Is inlet temperature at least 20°C? (cold = thick)
2. Is pipe diameter large enough?
3. Is flow rate too high?
4. Is the material actually in the database correct?

**Solutions:**
- Heat material to 30-35°C
- Increase pipe diameter
- Reduce flow rate
- Verify material spec

### "Cream time is wrong"
**Note:** Cream times are at 25°C. Adjust for actual temperature:
- Each 5°C increase → 10-15% faster
- Each 5°C decrease → 10-15% slower

### "Material is too stiff to pump"
**Check:** Is it XHD RC or another high-viscosity material?
- XHD RC requires 35-45°C mold (not room temp!)
- Requires high-pressure machine (100-200 bar)
- Not suitable for low-pressure equipment

## Material Selection Decision Tree

```
Need rigid foam?
├─ YES: Need zero GWP?
│   ├─ YES: Strength important?
│   │   ├─ YES: Use Ecofoam XHD RC (best strength)
│   │   └─ NO: Use Ecofoam HD12 or HD20 (general)
│   └─ NO: Budget tight?
│       ├─ YES: Use Ecofoam HD12
│       └─ NO: Use Genfoam HD20 (denser, stronger)
│
└─ NO: Need flexible foam?
    ├─ YES: Use Flexo Soft or Medium (density choice)
    └─ NO: Need spray application?
        ├─ YES: Use Ecomate Spray Grade
        └─ NO: Use Semirigid Structural
```
